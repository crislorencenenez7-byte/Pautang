PAUTANGMO VERCEL SETUP

Required environment variables:
- FIREBASE_SERVICE_ACCOUNT = complete NEW Firebase service-account JSON from project pautangmo-f6fe0
- RESEND_API_KEY = your Resend API key
- MAIL_FROM = verified sender address allowed by Resend
- ADMIN_EMAIL = email address that should receive new loan application notifications and may access admin by email
- FIREBASE_STORAGE_BUCKET = optional; defaults to pautangmo-f6fe0.firebasestorage.app

Never put the service-account private key or Resend API key in firebase-config.js or GitHub.

WORKFLOW
1. Register -> Firebase Authentication -> email verification -> users/{uid}.
2. Apply Loan -> loanApplications/{loanId} and users/{uid}.loanActive=true / borrowingEnabled=false.
3. The borrower cannot submit another loan while an Unpaid loan exists.
4. Admin receives a Resend email containing the loanApplications data. No payment email is sent.
5. Pay Loan -> payApplications/{payId}. GCash proof is stored in Firebase Storage; Hands-On has no screenshot requirement.
6. Admin Dashboard reads both collections. Admin can verify/reject pending payments.
7. Verify & Mark Paid -> loanApplications.status=Paid and borrower borrowingEnabled=true.
8. Google Sheets remains a reporting copy of loan applications.

For Firebase Storage, enable Cloud Storage in the Firebase project before using GCash proof uploads.
